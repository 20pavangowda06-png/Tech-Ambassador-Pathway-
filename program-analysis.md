# Part A — Program Analysis & Comparative Matrix

## 1. GitHub Campus Experts

- **What it is:** GitHub Education's student leadership program. Campus
  Experts build inclusive tech communities on their campuses — running
  meetups, hackathons and workshops — and complete a 12-hour training
  (6 modules over 6 weeks) ending in a community proposal.
- **Eligibility (verified, GitHub Docs Oct 2026):** 18+ years old; enrolled
  in a formal higher-education institution; **more than one year left**
  before graduating; GitHub user for **at least six months**; student
  status validated through the **GitHub Student Developer Pack**; not in
  the Campus Advisors program.
- **Application cycle:** opens **every July for one month** (next window:
  **July 2027**). *Note: the course table lists a biannual Feb/Aug cycle —
  current GitHub Docs show an annual July window; plan for July 2027.*
- **Process:** application form (motivation, campus community challenges,
  opportunities you want to build) → video resume (2 weeks to submit if
  shortlisted) → decision.
- **Perks:** public-speaking, technical-writing and leadership training;
  event funding/support; a global network of student leaders; alumni
  status after graduation. Generally **one Expert per campus**.
- **Fit for Pavan:** strong — 5 public repos with real documented work,
  graduating 2030 (well over a year left), hackathon + team-project
  experience. Main gaps: Student Developer Pack not yet claimed, no
  event-organising track record yet.

## 2. HackerRank Campus Crew

- **What it is:** HackerRank's campus ambassador community. Crew members
  host coding contests and events on campus using HackerRank's platforms,
  with onboarding, a program manager contact, and reward tiers.
- **Eligibility:** passion for competitive programming and community;
  enrolled student; applicants pass a basic screening/quiz. Rolling
  applications (Spring/Fall intakes).
- **Application cycle:** **rolling** — can apply now; onboarding runs in
  cohorts.
- **Process:** application form → basic quiz/screening → onboarding
  (welcome kit, platform access, program-manager intro).
- **Perks:** host official campus coding contests; participant
  certificates for attendees; rewards scale with event size (Infinity
  Plan, mock-interview credits, merch at 300+ participants); career
  leads and a global crew network.
- **Fit for Pavan:** very strong — **3-star Problem Solving badge, 19/19
  accepted, 220 pts** is exactly the credibility this role needs; the
  CODE4CHANGE-2025 hackathon gives him event-participant perspective to
  flip into an organiser's. Main gaps: no contest-organising experience
  yet; 4th star (475 pts) would strengthen the application.
